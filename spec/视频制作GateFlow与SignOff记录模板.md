# 视频制作 GateFlow 与 SignOff 记录模板

每部片（系列则每集）开工时复制一份到项目目录，命名 `GATES.md`，随项目入库。本表只管「要达成什么、谁签、何时签」。

规则：

- 按顺序过，不跳 Gate；签字后才进下一 Gate
- 签字人是用户。AI 勾「达成」、填「自检」，不替用户签
- 后面发现前面 Gate 的问题：回到那个 Gate 改，在「回退记录」记一行，重签
- 自检只写一行结论（各项分数 + 过 / 不过）；分数明细放在对应文档末尾或回复里

## G1 选题

- 入口（勾一个）：
  - [ ] 想法未定：`STORYLINES.md` 写 ≥ 2 个真正不同的方向，各附 3–5 句画面口述，用户选一个
  - [ ] 想法已清晰：`STORYLINES.md` 把用户的想法复述成一个方向，附画面口述与 AI 补上的假设（受众、时长、结尾等），用户确认；AI 认为有明显更好的讲法时可附一个对照方向并写一句理由，没有就不附
- [ ] 写出「看完能说出 / 会感到……」那一句
- 自检（选题阶段各项）：
- SignOff：签字 ___ · 日期 ___ · 备注 ___

## G2 设计

- [ ] `SPEC.md`：段表（每段作用一句、关键帧 1–3 张）、逐段画面口述、全片「最记得住的一个画面」
- [ ] 科普 / 教学：每个数字、说法有出处；剧情：世界规则表
- 自检（设计阶段各项）：
- SignOff：签字 ___ · 日期 ___ · 备注 ___

## G3 样片

- [ ] 关键帧截图给用户看过
- [ ] 10–30s 样片，用同一条命令渲两遍，字节一致
- 自检（样片阶段各项）：
- SignOff：签字 ___ · 日期 ___ · 备注 ___

## G4 制作

- [ ] `build.py` 断言、本片校验脚本、`hyperframes check` 都 0 失败；新加的元素类型都有校验
- [ ] 开渲前页面加载与跳时刻无报错
- 自检（制作阶段各项）：
- SignOff：签字 ___ · 日期 ___ · 备注 ___

## G5 交付

- [ ] 渲染 → `deliver.py` 全部 OK
- [ ] 改动处与跨渲染接缝已抽帧看过；样片后新引入的渲染方式已补测确定性
- [ ] 盲测复述
- 自检（交付阶段各项）：
- SignOff：签字 ___ · 日期 ___ · 备注 ___

## G6 复盘

- [ ] 每条看片反馈：在本片改了，或写明不改的理由
- [ ] 对框架规范的建议（≤ 3 条）已提给用户，未擅自修改
- 自检（复盘阶段各项）：
- SignOff：签字 ___ · 日期 ___ · 备注 ___
