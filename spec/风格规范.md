# 风格规范

适用于所有片子的数值底线，HyperFrames 与 Manim 共用。底色、配色、字体等视觉方案每部片（或每个系列）自己定，写在它的 SPEC 或系列规范里。

## 1. 颜色

- 对比度对片子的底色实算（WCAG）：承载信息的文字 ≥ 4.5:1，图形 ≥ 3:1；不达标就加深或提亮
- 颜色不作唯一信息通道：必配文字标签、形状或线型（照顾色弱，也抗 yuv420p 色度抽样）

## 2. 文字

- 1080p 下画面文字一般 ≥ 36px，32px 是下限，只给数字、短标签；彩色文字 ≥ 36px 且字重 ≥ 500（彩色细字经色度抽样易糊）
- 一屏说明文字 ≤ 2 行、≤ 30 字
- 字体文件入库（LFS），不依赖系统安装；许可须允许入库与商用，附许可文件
- 同一字体只放一份：两个以上系列或单片用到的放框架 `shared/fonts/`，只一个系列用的放该系列 `common/fonts/`；后来别处也要用时移到 `shared/fonts/`，不复制

## 3. 线条与形状

- 承载信息的线 ≥ 3px，网格线 ≥ 2px，禁止 1px（平台重压后消失）
- 点直径 ≥ 12px

## 4. 版式

两个框，1080p 下的边距：

| 框 | 左右 | 上下 | 放什么 |
|---|---|---|---|
| 动作安全框（90%） | 96px | 54px | 承载信息的图形、焦点物体；停住时整个在框内 |
| 标题安全框（80%） | 192px | 108px | 一切文字：字幕、标题卡、标签、读数、公式 |

- 底边 108px 同时避开播放器的进度条与控件
- 两框之外只放不承载信息的东西（底纹、出入画途中的运动、满屏背景）

## 5. 动效

- 时长、缓动每部片自己定，这里只给底线
- 整屏静止超过 3s 要有理由（如留给阅读、有意的留白）；`hyperframes check` 的 `dead_stretch` 只是提醒
- 任意 1 秒内闪烁 ≤ 3 次；大面积亮度变化须 ≥ 0.3s 渐变，禁止全屏闪白
- 快动：60fps 下峰值超过约 15px/帧、画面又有大块深浅对比时加运动模糊；峰值不超过约 48px/帧
- 需要「随机」效果时用固定种子，保证每次出片相同

## 6. 阅读时长

这是下限：字幕停留不得短于它。时间线由画面动作排，字幕挂到动作上，不用阅读时长去排时间线。

- 文字停留 ≥ max(2s, 1s + 字数 × 0.25s)
- 字数：汉字各计 1；连续的英文字母、数字、小数点、下划线合计 1（如 `0.5`、`max_value`）；标点、空格、运算符不计
- 公式每多一项 +0.5s
- 从文字完全出现起算，到它发生下一次变化止

## 7. 声音

- 综合响度 −20 LUFS（±1），真峰值 ≤ −1 dBTP
- 由 `shared/py/common.py` 的 `Track.write` 在混音时归一并限峰（不达标即断言失败），成片由 `shared/py/deliver.py` 用 ffmpeg ebur128 复测
- 归一要靠大幅限峰才达到时（稀疏的短促音效），说明动作音太少或太轻，回到声音设计上改，不靠压缩硬拉
